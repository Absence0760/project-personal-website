## Core competencies

- **Custom application & web development** — web applications, multi-tenant

- **Principal-led delivery.** The engineer you contract with does the work —

  not an afterthought.
- **Security-conscious by default.** Least-privilege cloud setups and no
  unnecessary third-party code.
